# 002 — red-team round 1: self-play adversary beats c2

**Adversary:** parameter-search adversary (angle d, self-play), trained against fields containing two white-box c2 clones + live-calibrated market bots. Became c3.

## What the adversary did differently
- **kEarly 2.13 → 1.02, tEarly 2.11 → 2.22:** values tiles by *count* (enabling) much more than by face, so it buys cheap 1-point tiles that c2 under-bids, and stops overpaying for heavy letters it can't place.
- **pace 6.4 → 18.6 (looser per-auction cap):** c2's cap (~balance·6/rem) bound before its value did in the mid-game, so c2 under-bid tiles it valued highly while the adversary won them at c2's capped bid + 0.
- **playLen 4 → 6, tPlay 1.65 → 1.9:** cashes in only 6+ letter words mid-game (higher multiplier), still recycling cash.

## Root cause in c2
The spending cap was a blunt runway rule that duplicated what the adaptive λ already does. With λ handling the budget, the cap mainly blocked high-value bids. And face-weighted option value mispriced vowels and other 1-point tiles relative to their enabling value.

## Fix
Adopted the adversary's parameters as c3: a looser cap that is now only a safety net, plus count-based option value. Regression: c3 beat c1 (h2h 0.76, 0.91) and the hold-out zoo (1.002), and tied c2 in first-price (0.52).

Live c3, first 5 matches: places 4, 6, 3, **1 (139 pts)**, 4.
